# カーソルを追いかけるキャラのサイトの作り方

マウスを動かすと、キャラがそっちを向くWebサイトの作り方です。
プログラミングの知識はいりません。プロンプトはコピペでそのまま使えます。

---

## 用意するもの

| 使うもの | 何に使う | メモ |
|---|---|---|
| ChatGPT | キャラの画像を作る | 画像を作れる回数はプランによって違います |
| Gemini | キャラが動く動画を作る | 動画を作る機能は、プランによって使えないことがあります |
| Claude Code（または Codex） | 動画からWebサイトを作る | どちらも有料プランが必要です |
| パソコン（Mac / Windows） | | スマホだけでは作れません |

全体の流れ：**キャラ画像 → 動画 → Webサイト**

---

## ステップ1：ChatGPTでキャラを作る

自分の写真から作るか、文章だけで作るか、どちらかを選んでください。

### A. 自分の写真から作る
写真をアップロードしてから、次のプロンプトを送ります。

```
添付した写真の人物をもとに、キャラクターのイラストを作ってください。

【テイスト】
（例：ゆるい手描き風／3Dアニメ風／ドット絵風 など好きなものに書き換えてください）

【必ず守ること】
・正面を向いた、胸から上のキャラクター
・キャラクターは画面の真ん中に置く
・頭のまわりに余白をしっかりとる（あとで首を動かすため）
・背景は無地の単色（白か薄いグレー）。模様や小物は入れない
・横長（16:9）の画像
```

### B. 文章だけで作る

```
次のキャラクターのイラストを作ってください。

【キャラクター】
（例：メガネをかけた白いフクロウ。ちょっと眠そうな目）

【テイスト】
（例：ゆるい手描き風／3Dアニメ風／ドット絵風 など）

【必ず守ること】
・正面を向いた、胸から上のキャラクター
・キャラクターは画面の真ん中に置く
・頭のまわりに余白をしっかりとる（あとで首を動かすため）
・背景は無地の単色（白か薄いグレー）。模様や小物は入れない
・横長（16:9）の画像
```

できた画像は保存しておきます（画像を右クリック →「画像を保存」）。

> **注意**：ネットで拾った他の人のイラストや写真を元にキャラを作るのはやめましょう。作者の権利を侵害するおそれがあります。

## ステップ2：Geminiでキャラが動く動画を作る

1. Geminiを開いて、ステップ1のキャラ画像をアップロード
2. 入力欄の「＋」から「動画」を選ぶ
3. 縦横の比率を「16:9」にする
4. 次のプロンプトを貼って送信

```
添付したキャラクターが、その場で首と目を動かして、いろいろな方向を見る動画を作ってください。

【動きの順番】
1. はじめの1秒は、正面を向いたまま止まる
2. 左 → 左上 → 上 → 右上 → 右 → 右下 → 下 → 左下 → 左 の順に、時計回りでゆっくり1周見回す
3. 最後の1秒で正面に戻って止まる

【必ず守ること】
・カメラは完全に固定。ズーム・パン・揺れは一切なし
・キャラの位置と大きさは最初から最後まで変えない。動くのは頭と目だけ
・背景は元の画像のまま変えない
・まばたき以外の表情はあまり変えない
・音はなし
```

生成が終わったら、動画をダウンロードします。

> **うまくいかないとき**：キャラが歩き出したり、カメラが動いたりしたら、もう一度生成してください。「カメラは完全に固定」の部分を何度か書き足すと安定しやすくなります。

## ステップ3：フォルダを作って動画を入れる

デスクトップなどに新しいフォルダを作り（名前は自由。例：`cursor-chara`）、ステップ2の動画を入れます。

---

## ステップ4：Claude Code（またはCodex）でWebサイトにする

1. Claude Code（またはCodex）を開く
2. ステップ3のフォルダを選ぶ
3. 次のプロンプトを貼って送信

```
このフォルダにある動画を使って、マウスカーソルの方向をキャラクターが見るWebサイトを作ってください。

【やってほしいこと】
1. 動画からフレーム（コマ）を画像として書き出し、中身を見て、それぞれのコマでキャラが「正面・上・右上・右・右下・下・左下・左・左上」のどの方向を見ているかを調べる
2. カーソルが「キャラの顔から見てどの方向にあるか」を計算し、その方向を見ているコマを表示する
3. カーソルが顔のすぐ近くにあるときは、正面を向いたコマを表示する
4. コマの切り替えはなめらかにして、急に飛ばないようにする
5. スマホでは、指でなぞった位置を追いかけるようにする

【サイトの見た目】
・キャラは画面の真ん中に、なるべく大きく表示する
・背景は動画の背景と同じ色で、画面いっぱいに塗る
・余計な文字やボタンは置かない

【仕上げ】
・index.html をダブルクリックするだけで動く形にする（サーバーなしで動くように）
・完成したらブラウザで開いて、カーソルの方向とキャラの向きが合っているか確認する
```

完成したら、フォルダの中の `index.html` をダブルクリックして開いてみてください。
カーソルを動かすと、キャラが追いかけてくれます！

## うまくいかないとき

| 困ったこと | こう頼んでみてください |
|---|---|
| カーソルと逆の方向を向く | 「カーソルと逆を向いているので、向きを直して」 |
| 動きがカクカクする | 「動きがカクカクするので、もっとなめらかにして」 |
| キャラが小さい／はみ出す | 「キャラをもっと大きく（小さく）して」 |
| 「ffmpegがない」と言われた | 「必要なものを入れて、続けて」と送れば、AIが準備してくれます（インストールの許可を聞かれたら「OK」） |
| 画面が真っ白で何も出ない | 「index.htmlを開いても何も表示されないので、原因を調べて直して」 |

---

## もっと楽しむアレンジ

できあがったサイトに、Claude Code（Codex）でもう一言頼むだけで追加できます。

- 「クリックしたら、キャラがびっくりするようにして」
- 「カーソルを長く止めていたら、キャラが眠るようにして」
- 「キャラの横に、会社名とキャッチコピーを入れて」→ そのまま会社サイトやLPのトップに使えます
